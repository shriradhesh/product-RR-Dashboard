# Product Ratings and Review Analytics Dashboard

A full-stack dashboard for analyzing Amazon product data, ratings, and reviews.

## Features

- 📊 Dashboard with interactive charts and analytics
- 📁 Excel/CSV data import functionality
- 🔍 Product search with filters (category, rating)
- 📈 Visualizations: Products per category, Top reviewed products, Discount distribution, Category-wise ratings
- 📋 Data table with pagination and export options
- 🎨 Modern UI with Material-UI components

## Tech Stack

### Backend
- Node.js with Express
- PostgreSQL with Sequelize ORM
- Multer for file upload
- XLSX for Excel processing

### Frontend
- React 18
- Redux Toolkit for state management
- Material-UI for components
- Recharts for visualizations
- Axios for API calls

## Prerequisites

- Node.js (v14 or higher)
- PostgreSQL (v12 or higher)
- npm or yarn
